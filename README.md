# Granary 

## Overview
Granary is a hands-off medieval kingdom simulation. The goal is
for many settlements to trade with each other over centuries, so that an
economy and unexpected behaviour emerge from simple rules.

## Status

Currently, it models one settlement of individual people who farm, eat, reproduce and die. With important metrics like population, total food and total deaths recorded and plotted.


## Project Structure


sim/ - contains the simulation code (Person / Settlement)  
tests/ - contains the pytest tests  
runtime/ – contains the file for running simulation with plotting    
config.py - tuning constants
